# Amby

Прототип приложения для белого шума и фоновых звуков в духе ELPY: несколько звуков играют одновременно, у каждого своя громкость. Есть готовые сеты, можно сохранять свои миксы и добавлять свои звуки.

## Стек

- **Flutter**: Android, iOS, Windows, macOS, Linux.
- **flutter_soloud**: аудиодвижок. Каждый звук — отдельный зацикленный голос, смешивает их SoLoud.
- **shared_preferences**: хранение своих звуков, сетов и общей громкости.
- **file_picker** и **path_provider**: импорт своих аудиофайлов и картинок. Файлы копируются в папку приложения.
- **Четыре оформления** (кнопка с палитрой в шапке): ASCII, Retro (пиксели с дизерингом, `shaders/pixel.frag`), Neumorphism (мягкие выпуклые карточки, обычные фото) и Air (стекло и «альбомные» обложки в духе iOS). Акцентный цвет выбирается для любого оформления. Токены лежат в `lib/look/look.dart`, компоненты — в `lib/look/components.dart`, карточки звуков — в `lib/ui/sound_tile.dart`.
- **Оформление ASCII в стиле Nothing**: чёрный и белый плюс акцентный цвет, который выбирается кнопкой в шапке. Шрифты лежат в `assets/fonts` (лицензия OFL): точечный Doto для цифр и латиницы (кириллицы в нём нет) и IBM Plex Mono для остального текста.
- **ASCII-шейдер** (`shaders/ascii.frag`): обложка звука рисуется символами ` .:-=+*#%@`. Пока звук играет, по символам бежит волна.

## Структура

| Файл | Что внутри |
|---|---|
| `lib/models.dart` | `Sound` и `SoundSet` с сериализацией в JSON |
| `lib/catalog.dart` | встроенные звуки и готовые сеты |
| `lib/audio_engine.dart` | обёртка над SoLoud: старт и стоп с фейдом, громкость, пауза |
| `lib/app_state.dart` | `ChangeNotifier`: текущий микс, сеты, свои звуки, таймер сна |
| `lib/look/` | оформления: токены и темы (`look.dart`), общие компоненты (`components.dart`) |
| `lib/art/` | ASCII-шейдер (`AsciiArt`), атлас глифов, загрузка картинок и иконок |
| `lib/ui/` | сетка звуков, сеты, панель микса, микшер, таймер, редактор своего звука (`sound_editor.dart`) |
| `tool/gen_sounds.sh` | генератор бесшовных петель-заглушек в `assets/sounds/` (нужен ffmpeg) |

## Запуск

```bash
flutter pub get
flutter run            # Android-устройство или эмулятор
flutter run -d linux   # нужны clang, cmake, ninja (sudo pacman -S clang cmake ninja)
```

## Звуки

В `assets/sounds/` лежат синтезированные заглушки: шумы, «дождь», «океан» и т. п. Их стоит заменить на реальные записи.
- Формат: OGG или WAV. MP3 не подходит, потому что из-за паддинга кодека на стыке петли будет щелчок.
- Конец петли должен гладко переходить в начало. Как это сделать кроссфейдом, показано в `tool/gen_sounds.sh`.

## Что дальше

- Фоновое воспроизведение и управление с экрана блокировки через `audio_service`. На Android для этого нужен foreground service, на iOS — режим Background Audio.
